# Stage 01 — Coordinate System and Dimensions

## Target envelope

The complete kart must fit inside this axis-aligned envelope:

- X width: `1.20 m` maximum
- Y length: `1.80 m` maximum
- Z height: `1.05 m` maximum
- Ground contact: wheel bottoms at `Z = 0.00 m`, tolerance `0.01 m`

Front is negative Y. Rear is positive Y. The kart centerline is X = 0.

## Reference dimensions

- Wheelbase: `1.10 m`, tolerance `0.02 m`
- Front track: `0.92 m`, tolerance `0.02 m`
- Rear track: `0.96 m`, tolerance `0.02 m`
- Wheel outer diameter: `0.34 m`, tolerance `0.01 m`
- Wheel width: `0.14 m`, tolerance `0.01 m`

Create non-rendering reference guides if helpful, place them in `KART01_PRESENTATION`, and name them with the prefix `REF_`.
