# Simplified worker workflow

1. Run `python3 scripts/check_resume.py`; inspect RUN_STATE.json. Check worker authoring availability and diagnostics tool. Record selected model and assistance.
2. Read support/kart/helpers.py, then write the actual build body. Combine helper text followed by build text into one saved artifacts/scripts/build.py and submit that text as code. Call setup(), then author parts. The helpers are not a complete generator. No repository imports are available inside /job.
3. Record accepted job/source in RUN_STATE.json before polling. On completion inspect scene.json and report.json, fetch scene.blend and verify manifest hash. Checkpoint locally at artifacts/blend/Kart01.blend. Record checkpoint path and sha256. Never treat worker execution passed as asset acceptance.
4. For review concatenate helper text + presentation.py + validate.py and submit against the completed build source. The rig is idempotent for its own named objects; do not run it on arbitrary user scenes. Read the validation report even when passed is false. The validator reports failures without raising, so worker success does not mean validation passed. Preserve the report. Repair geometry using a source known to contain the asset, then rerun review.
5. Marker frames 1–4 select perspective/front/side/rear. Verify renderer supports authored camera markers; otherwise use four authoring revisions selecting scene.camera explicitly, rendering each. The renderer must use the actual scene, not a fallback camera. Use queued GPU rendering and respect protected sessions. Fetch frames to the four specification names, inspect each, record visual checklist outcomes.
6. Export selected root and descendants only, with modifiers/materials/normals. Write /job/Kart01.glb; worker automatically writes /job/scene.blend. Download and verify outputs. Reimport GLB in a separate isolated job; record geometry/material and presentation-exclusion checks. Do not overwrite the final source with the reimport scene.
7. Save the report.json validation evidence as artifacts/reports/validation.json; write BUILD_REPORT.md with visual and round-trip evidence, versions, dimensions, triangles, settings, jobs and defects. Run python3 scripts/check_delivery.py. Set state COMPLETE only after objective, visual, round-trip and local checks pass.

Worker scripts execute under __blender_author__, not __main__; top-level calls are unconditional. Extra files use flat /job paths. Local files are not uploaded by mentioning them. Poll existing jobs rather than resubmitting. Failed CPU jobs: diagnostics once, change the failing code based on traceback, stop after three unsuccessful repairs of the same issue. Never fetch completed artifacts from failed jobs. No remote work or Blender runtime verification was performed when preparing this branch.
